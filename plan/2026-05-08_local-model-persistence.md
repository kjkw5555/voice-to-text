# Implementation Plan: Local Model Persistence & Update Logic

- **Date:** 2026-05-08
- **Status:** Completed (2026-05-08)

## Overview
Whisperモデルをプロジェクト内のローカルディレクトリ（デフォルトでは `./models`）に保存し、起動時に存在チェックおよび最新バージョンの確認を行うように仕様を変更します。

## Requirements
- **ローカル保存**: モデルファイルをプロジェクト内の特定のフォルダ（例: `models/`）に保存する。
- **存在チェック**: ローカルに存在しない場合のみダウンロードする。
- **最新チェック**: インターネット接続がある場合、リモートのハッシュと比較し、最新でなければ再ダウンロードする。
- **オフライン動作**: インターネットがない場合は、ローカルにあるモデルをそのまま使用する（存在する場合）。

## Architecture Changes
- `transcribe.py`:
    - モデル保存ディレクトリの定数（`MODELS_DIR`）を追加。
    - インターネット接続を確認するユーティリティ関数を追加。
    - モデルのハッシュ確認とダウンロードを制御する `ensure_model_exists` 関数（仮）を実装。
    - `transcribe_audio` 関数のモデルロード部分を、上記の新ロジックを使用するように変更。

## Implementation Steps

### Phase 1: 基礎機能の実装
1.  **ディレクトリ定数の追加** (File: `transcribe.py`)
    - `MODELS_DIR = "models"` を定義し、スクリプト実行時に自動作成されるようにする。
2.  **接続確認ロジックの追加** (File: `transcribe.py`)
    - 特定のホスト（OpenAIのモデルホスト等）に接続できるか確認する軽量な関数を実装。
3.  **モデル管理ロジックの実装** (File: `transcribe.py`)
    - `whisper._MODELS`（ハッシュリスト）を参照し、ローカルファイルの整合性をチェックする。
    - 接続可能かつハッシュが異なる（またはファイルがない）場合にダウンロードを実行。

### Phase 2: 既存フローへの統合
1.  **`transcribe_audio` の修正** (File: `transcribe.py`)
    - `whisper.load_model` を呼び出す前に新ロジックを実行し、`download_root` 引数に `MODELS_DIR` を指定する。
2.  **CLIオプションの追加** (File: `transcribe.py`)
    - `--models-dir` オプションを追加し、保存先をユーザーが変更できるようにする。
    - (任意) `--skip-update` オプションを追加し、ネットがあっても更新チェックをスキップできるようにする。

## Testing Strategy
- **Unit tests**: 
    - ネットワーク接続確認関数のテスト。
    - ハッシュ検証ロジックのテスト。
- **Integration tests**:
    - 初回実行時：`models/` フォルダが作成され、ダウンロードされることの確認。
    - 2回目以降（オフライン）：ダウンロードが発生せず、既存ファイルが使用されることの確認。
    - ファイル破損時：ハッシュ不一致を検知して再ダウンロードされることの確認。

## Risks & Mitigations
- **Risk**: 起動時のアップデートチェックによる遅延。
    - **Mitigation**: タイムアウトを短く設定し、失敗した場合は即座にローカルモデルの使用に切り替える。
- **Risk**: Whisperライブラリの内部仕様変更。
    - **Mitigation**: Whisperの標準API (`download_root`) を極力利用し、複雑なハッシュ計算はライブラリに任せる。

## Success Criteria
- [x] `./models` ディレクトリに `.pt` ファイルが保存される。
- [x] オフライン状態でも、一度ダウンロード済みのモデルがあれば正常に動作する。
- [x] ネット接続時に、意図的に破損させたモデルファイルが自動修復（再ダウンロード）される。
